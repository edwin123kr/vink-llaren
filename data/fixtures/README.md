# Testdata

- `xwines-test-100.csv` – X-Wines testversion (100 viner), CC0-1.0, från
  https://github.com/rogerioxavier/X-Wines. Citera: de Azambuja, Morais & Filipe (2023),
  *X-Wines: A Wine Dataset for Recommender Systems and Machine Learning*, Big Data Cogn. Comput. 7(1), 20.
- `off-exempel.jsonl` – handskrivna testrader i Open Food Facts-format för enhetstester.
  EAN-koderna börjar på `200` (reserverat för internt bruk) och motsvarar inga riktiga produkter.
  Importeras aldrig till katalogen.
