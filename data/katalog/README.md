# Större vinkatalog

Lägg X-Wines-filen här (t.ex. `XWines_Full_100K_wines.csv` eller komprimerad som `.csv.gz`).
Vid start läses den in automatiskt om katalogen bara innehåller testurvalet. Dubbletter hoppas över,
så det är ofarligt att den ligger kvar.

Ladda ner från X-Wines: https://github.com/rogerioxavier/X-Wines (länkarna till "Slim" och "Full"
leder till Google Drive). Licens CC0.
